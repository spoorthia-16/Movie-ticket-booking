# Movie-ticket-booking
QuickShow is a full-stack movie ticket booking web application that allows users to browse movies, view show timings, select seats, and book tickets through a simple and interactive interface. The project aims to provide a seamless online ticket booking experience similar to real-world movie booking platforms.

🚀 Features
🔐 User Authentication & Authorization
🎥 Browse Movies and Movie Details
🕒 View Show Timings
💺 Seat Selection & Ticket Booking
🎟 Booking Confirmation
📱 Responsive User Interface
🗂 Booking History Management
⚡ Fast and Interactive Experience
