# Movie-ticket-booking
# Overview

Movie ticket booking web application developed to provide users with an easy and interactive platform to browse movies, check show timings, select seats, and book tickets online.

# Features
User Authentication & Authorization
Browse Movies and Show Details
View Show Timings
Seat Selection & Ticket Booking
Booking Confirmation System
Responsive User Interface
Booking History Management
# Technologies
React.js
Node.js
Express.js
MongoDB
HTML
CSS
JavaScript
# Modules
User Management
Movie Management
Seat Booking System
Payment & Confirmation
Booking History
